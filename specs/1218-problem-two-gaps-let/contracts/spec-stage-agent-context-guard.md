# Contract: spec-stage agent-context guard

**Enforced by**: behavioral unit tests —
`packages/orchestrator/src/worker/__tests__/pr-manager.agent-context-revert.test.ts` (guard) and
`packages/workflow-engine/src/actions/github/client/__tests__/gh-cli.revert-paths.test.ts`
(revert primitive). There is deliberately **no** static-grep guard (clarification Q4 — #899's
lesson is that a grep aimed at the wrong file yields false confidence).

## The invariant

> An engine-made phase-completion commit for a spec-stage phase (`specify`, `clarify`, `plan`,
> `tasks`) never contains a repo-root agent-context file (`CLAUDE.md`, `AGENTS.md`, `GEMINI.md`,
> `.github/copilot-instructions.md`), and the working tree is left clean of dirty agent-context
> state afterwards (tracked → restored to HEAD, untracked → deleted), with a warning naming the
> reverted paths.

## Scope

- **Phase scope**: spec-stage only, derived as `PHASE_TO_STAGE[phase] !== 'implementation'`.
  Implement-and-later phases commit agent-context edits unchanged — implement-phase `CLAUDE.md`
  edits can be legitimate durable guidance (Q1).
- **Path scope**: exact equality against `EXCLUDED_EXACT_PATHS`
  (`packages/orchestrator/src/worker/product-diff.ts`) — the single source of truth. Not
  `startsWith` (`CLAUDE.md.bak` must pass), not basename matching
  (`packages/<pkg>/CLAUDE.md` must pass).
- **Mechanism scope** (Q2): staging filter only. If a spec-stage agent runs `git commit` itself
  and includes an agent-context file, that commit is pushed untouched — commit rewriting is
  materially riskier than declining to stage. Documented in the code comment beside the filter.

## Required behaviors

1. Excluded paths are removed from the stage/commit pathspec *before* `stageFiles`/`commit`;
   the commit pathspec is explicit, so a pre-staged agent-context file in the index is never
   folded in.
2. When exclusion empties the commit entirely, the phase proceeds as a normal `no-changes`
   outcome (Q3) — not an error — and the warning still fires.
3. The revert is best-effort: a `revertPaths` failure is logged and must never abort the product
   commit/push.
4. The warning log names every reverted path (operator signal).
